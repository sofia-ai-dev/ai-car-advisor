AI Car Advisor

Интеллектуальный помощник для выбора рамных внедорожников на основе анализа данных из Auto.ru.
Что умеет?
- Анализирует характеристики автомобилей
- Фильтрует по году выпуска, объёму двигателя, типу КПП
- Выдаёт персонализированные рекомендации
- Работает на базе LangChain + OpenAI API

Данные
Информация взята из статьи Auto.ru: "Огромные рамники с пробегом по цене китайского кроссовера"

Технологии
- Python 3.8+
- LangChain для обработки естественного языка
- OpenAI API для генерации ответов
- Telegram Bot API для интерфейса

Установка
1. Клонируйте репозиторий
2. Установите зависимости: `pip install -r requirements.txt`
3. Настройте API ключи в `.env` файле
4. Запустите: `python main.py`
