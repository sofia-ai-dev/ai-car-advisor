 AI Car Advisor (Autonomous Agent)

Интеллектуальный агент на базе LangChain и OpenAI API для подбора рамных внедорожников (body-on-frame SUV) на основе строго заданных технических характеристик.

 🌟 
 Особенности проекта
- Архитектура Agentic RAG: Использует инструменты (Tools) для извлечения данных, что исключает галлюцинации модели.
- Строгая валидация: Системный промпт ограничивает модель только предоставленными данными.
- Масштабируемость: Легко расширяемый датасет и возможность подключения реальных API (Auto.ru, Drom).
- Технологический стек: Python 3.9+, LangChain Core, OpenAI API, Type Hinting.

 🛠 Технологии
- LangChain: Для оркестрации агента и связки LLM с инструментами.
- OpenAI GPT-4o-mini: Быстрая и эффективная модель для обработки запросов.
- Python Tools: Кастомные функции для фильтрации данных.

 📂 
 Структура проекта
- `advisor.py`: Основной код агента, определение инструментов и логика выполнения.
- `requirements.txt`: Зависимости проекта.
- `.env`: Конфигурация API ключей.

 🏃‍♂️ 
 Как запустить
1. Установите зависимости:
```bash
   pip install -r requirements.txt
```
2. Настройте переменные окружения в файле `.env`:
```env
   OPENAI_API_KEY=sk-your-actual-api-key-here
```
3. Запустите агента:
```bash
   python advisor.py
```

 🧪 
 Пример использования
Агент может отвечать на сложные запросы, например:
> *"Найди рамный внедорожник с клиренсом от 215 мм и дизельным двигателем."*

Агент автоматически вызовет инструмент `get_suv_by_specs`, отфильтрует данные и вернёт точный ответ без выдумок.
